# Gnosis

A Christian trivia game where rarer answers earn more Manna: worship songs, the Bible and Bible characters.
Includes **Chokmah Garden**, the live multiplayer mode for up to 12 players (beta), powered by Firebase.

**Play:** https://gnosis-trivia.github.io/Gnosis/

Created by Aloysius Lee Jian Xi.

## Files
- `index.html`: the game page, built from the Claude artifact's page by `tools/site.py`
- `data.js`, `engine.js`, `kjv.json`: prompts, answers, scoring and King James verse text (updated daily)
- `room.js`: Chokmah Garden's live rooms on Firebase
- `preview.jpg`, `icon-180.png`: the link preview and home-screen icon
